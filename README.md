# News homepage

A responsive news homepage built with HTML, CSS, and vanilla JavaScript. It includes a mobile navigation menu, featured story, new stories panel, and trending article cards.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static HTTP server. No build step or package installation is required.

## Project files

- `index.html` — page structure and article content
- `style.css` — responsive layout, styling, and local Inter font setup
- `Script.js` — mobile navigation and the featured story button interaction
- `assets/` — images and local font files

The hero image switches to the mobile asset at viewport widths of 600px and below.
